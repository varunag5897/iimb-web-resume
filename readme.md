# Varun Agarwal - Personal Resume Website

## Project Description

This is my personal resume and portfolio website,
developed using HTML5 and CSS3 as part of my
Web Development assignment.

The website showcases my education, skills,
experience, achievements and contact information.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Flexbox
- CSS Grid
- CSS Media Queries

## Website Sections

1. Home - Personal introduction
2. About - Brief personal profile
3. Education - Academic background
4. Skills - Technical and creative skills
5. Experience - Professional and creative experience
6. Achievements - Awards and accomplishments
7. Contact - Contact information

## CSS Features Implemented

- Custom typography using Google Fonts
- Consistent colour palette
- Class, ID and element selectors
- Flexbox and Grid layouts
- Sticky navigation bar
- Positioning properties
- Hover effects and transitions
- Responsive media queries
- Smooth scrolling
